# UK Locksmith LTD

Official website for UK Locksmith LTD (`uklocksmithltd.site`), providing 24/7 emergency and standard locksmith services across London.

## Tech Stack

- **Framework**: React 18 (JSX, plain JavaScript)
- **Bundler & SSG**: Vite + `vite-react-ssg`
- **Routing**: `react-router-dom` v6
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Animation**: Framer Motion
- **SEO/Head**: `react-helmet-async`
- **Hosting Target**: Vercel

## Scripts

- `npm run dev`: Start local development server
- `npm run build`: Pre-render all routes to static HTML via `vite-react-ssg`
- `npm run preview`: Preview the static build output locally
